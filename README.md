# Utilitaire-Huffman
Création d'un outil utilisant le codage de Huffman pour compresser et décompresser des fichiers à partir de l'algorithme de Huffman.

# Contribuer
Si vous utilisez un IDE comme Netbeans ou VSCode, veuillez bien ajouter vos fichiers java correspondant à l'architecture du logiciel et pas les métadonnées !

# Paquetages

La racine du projet est iut.info1.codageHuffman<br>
Les fichiers sources se trouvent dans iut.info1.codageHuffman.src<br>
Quant aux tests, ils sont dans iut.info1.codageHuffman.test<br>
