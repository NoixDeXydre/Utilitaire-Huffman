# Utilitaire-Huffman
Création d'un outil utilisant le codage de Huffman pour compresser et décompresser des fichiers à partir de l'algoryhme de Huffman.

# Contribuer
Si vous utilisez un IDE comme Netbeans ou VSCode, veuillez bien ajouter vos fichiers java correspondant à l'architecture du logiciel et pas les métadonnées !
